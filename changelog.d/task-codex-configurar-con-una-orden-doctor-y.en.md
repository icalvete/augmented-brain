- **`augmented-brain codex install` sets augmented brain up in Codex with one command
  (experimental).** It adds a plugin with the session start, the guard and the task
  tools, trusts its hooks for you and turns off `unified_exec_tty`, which let the
  assistant type where the guard could not see. No file of Codex to edit by hand. `codex
  status` and `doctor` say what is wrong and how to fix it; `update` trusts the hooks
  again when a new version changes them; `codex uninstall` removes it. On Linux and macOS
  the guard also stops a command when its program is missing. How to carry on a task in
  Codex is in a new guide, [Carry on in
  Codex](https://icalvete.github.io/augmented-brain/guide/codex.html).
