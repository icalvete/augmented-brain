- **Ask Claude for root on a machine, and confirm it.** A new tool, `root_exception_save`,
  adds a temporary root exception (a machine and an end date) when you ask for one.
  Claude Code always asks you first, showing the machine, the date and what it is for,
  so it works from a session you follow on another device, where the panel only shows.
  A new exception, from Claude or the panel, ends within 30 days and cannot start in
  the past; a machine keeps one exception, and adding it again changes its date.
