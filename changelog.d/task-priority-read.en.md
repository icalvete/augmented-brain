- **Tasks are listed by priority.** The index, the panel and "where were we?" put first
  the tasks with a deadline (`due`), the nearest first, then the important ones
  (`importance: high`), then those waiting on you, then the rest; a deadline in the next
  7 days comes up at the start of the session. This release reads both fields, which you
  can add by hand to a task's header; Claude will set them in a coming release, once
  earlier versions read them too.
