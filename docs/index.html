Your AI assistant forgets everything when the session ends.

augmented brain gives it a memory and a way of working: tasks, areas and rules it remembers from one session to the next, kept as Markdown files you own.

  1. curl -fsSL https://github.com/icalvete/augmented-brain/releases/latest/download/install.sh | sh
  2. augmented-brain init
  3. augmented-brain doctor

Linux or macOS, with Claude Code. No root needed. Then open Claude Code in your work folder. If the command is not found after installing, open a new terminal.

What you get

Tasks that last

Every piece of work goes through define, analyse, plan, execute with a journal, validate and close. Park it, resume it in any session.

Areas

Each responsibility, from your platform to a side project, groups its tasks and what you learned about it.

Rules that stick

How you like to work is loaded in every session. The important rules are enforced, not just asked for.

A guard

No commit or push unless you allow it, never root, no secrets in commands or files. Production AWS profiles and untouchable hosts ask you first, also over ssh.

Work and personal apart

Each space has its own memory, rules and backup. The folder you open the assistant in picks the space.

Backup and restore

Each space goes to a private git repository of yours. Lose your laptop and get everything back on a new one.

Commands

A handful, to set things up. Everyday work happens inside Claude Code.

CommandWhat it does
augmented-brain initSet up augmented brain and your first space
augmented-brain space addAdd another space: personal, a client…
augmented-brain doctorSay what is missing, and how to fix it
augmented-brain checkCheck the notes of this folder's space and rebuild its index
augmented-brain backup setup <url>Back up this space to a private git repository
augmented-brain backupSave the latest changes (--all for every space)
augmented-brain restore <url>Bring a space back on a new machine

In Claude Code, plain words do: “new task…”, “what is pending?”, “park it”, “note this in the inbox”.
