A memory, a method and a guard

Three things your assistant was missing. You talk to it as usual; this is what changes.

A memory

Every task, decision and lesson is a Markdown file on your computer. Each session reads them first, so it starts where the last one stopped.

Open them with any editor. No account and no cloud: if you stop using augmented brain, your notes stay. Your notes.

A method

Every task goes through the same six phases, like a pilot's checklist. You approve the definition, the plan and the result; inside each phase, the assistant just works and keeps a journal.

“Park it” saves where you are and the next step, like a bookmark. Tasks.

  1. DefineWhat we want, and how we'll know it worked.
  2. AnalyseHow things really are. Checked, not guessed.
  3. PlanSteps in order, each one reversible.
  4. DoWork, with a dated journal.
  5. CheckProve it works, for real.
  6. CloseKept, never deleted.

A guard

Before every command Claude runs, the guard checks your rules. A few things stop, a few ask you, and everything else runs as usual. Even when the command hides inside another one, or goes over ssh.

You decide what is production and what must not be touched. The guard.

git commit -m "…" && git pushstoppedcommits and pushes are yours, unless you allow a repository
sudo apt remove nginxstoppednever as root, unless you allow it on one machine until a date
export API_KEY=sk-…stoppedno secrets in commands or files
aws --profile prod s3 rm …asks youproduction is yours to approve
ssh db01 "systemctl restart …"asks youa host you said not to touch
aws --profile dev s3 lsgoes aheadeverything else runs as usual

Install it

Linux, macOS 13 or later, or Windows 10 or 11 · a paid Claude account (Pro or above) · a few minutes. Never opened a terminal? Getting started goes step by step. What changes on each system: Installing.

  1. Open the terminal.On a Mac, press Cmd + Space and type Terminal. On Ubuntu, Ctrl + Alt + T. On Windows, open PowerShell.
  2. Paste the install command.Then press Enter.
    On macOS or Linux, in the terminal:
    curl -fsSL https://github.com/icalvete/augmented-brain/releases/latest/download/install.sh | sh
    On Windows, in PowerShell:
    irm https://github.com/icalvete/augmented-brain/releases/latest/download/install.ps1 | iex
  3. Answer the installer.The language, whatever is missing (git, Claude Code, the Claude app) and whether to open Claude now. Enter accepts what it suggests.
  4. Sign in to Claude.In the Claude app, with your paid account: open the Code tab, click + New and say hi.
  5. Answer the interview.The first time, Claude asks six quick questions, one at a time, and offers to set up the backup. Say yes.

If something is off, augmented-brain doctor tells you what is missing and how to fix it.

And also

  • A backup of yours. Each space can go to a private git repository you choose, by itself after every session. A new computer gets it all back with one command. Backup.
  • Work and personal, apart. Each space has its own notes, rules and backup; the folder you open picks it. Spaces.
  • Reminders and an inbox. “Remind me on Thursday…” comes up on Thursday. A loose idea goes to the inbox, without opening a task. What to say.
  • A weekly review. Empty the inbox and look at stalled tasks, one at a time, in about ten minutes. Weekly review.
  • Your services. Calendar, mail, documents and Jira can join in. Connect services.
  • From anywhere. Reach Claude on your computer from your phone or another computer, also after a reboot. Remote access.

Questions

Is it free?

augmented brain is: open source, under the MIT license, with no account and no subscription. But it works with Claude Code, which needs a paid Claude account (Pro or above).

Do my notes leave my machine?

augmented brain never sends them anywhere: they stay in files on your machine. Your assistant reads them to work, like any other file it opens, so they travel with the conversation. With a backup, they also go to a private git repository you choose.

Which assistants does it work with?

Claude Code, today: in the Claude desktop app or in a terminal. The tools for your notes run as an MCP server, which other assistants speak too. But reading your notes at the start of a session and the guard rely on Claude Code's hooks, so no other assistant is supported yet.

Does it work on Windows?

Yes: Windows 10 and 11, with one PowerShell command. Claude runs its commands in Git Bash, which the installer sets up, so the guard works there too. See Installing.

What happens when I run out of Claude usage?

Your task sessions wait and go on by themselves. On Linux, with remote access installed, augmented brain reads when the limit resets and wakes each session then, with its whole conversation. It tells you when the wait begins and when they are back. See A session per task.

What if I stop using it?

Your notes stay where they are, as plain files. There is nothing to export.
