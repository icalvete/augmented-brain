What it does, day to day

You talk to it as usual. This is what changes.

“Where were we?”

It lists your live tasks, each with its next step and who is holding it up.

“Park it, we carry on tomorrow.”

It writes down where you stopped and what comes next. Tomorrow, in a new session, it starts there.

“Note: renew the certificate in November.”

It goes to the inbox, without opening a task. You sort it out in the weekly review.

“Remind me on Thursday to call the insurance.”

On Thursday, as soon as you open Claude, it reminds you. The same with a date on a task: “check in November that the certificate was renewed”.

“Why did we pick Postgres?”

It looks it up in your notes and gives you the decision, with its date and its reason.

“Save that as a lesson.”

What you learned gets its own note. Next time the topic comes up, it already knows.

“Delete the old production bucket.”

Before running it, it asks you. Production is yours to approve.

You open Claude in ~/augmented-brain/personal

It only sees your personal notes. Work stays in its own drawer.

“Tell Marcos we moved it to Monday.”

It knows Marcos is your manager, because you told it on day one, and drafts the message.

Three things your assistant was missing

A notebook

Every task, decision and lesson goes into a plain text file on your machine. Next session, the assistant reads it first.

“Which fields did the form have?” It's in its task, with the date.

A method

Like a pilot's checklist: every task goes from idea to done in the same six steps. Nothing is left half said.

“Park it” saves where you are and the next step, like a bookmark.

A doorman

Some doors stay shut unless you open them: pushing code, running as root, writing a password into a file.

The assistant has to ask you first.

The life of a task

Six steps, like a recipe. You say “go” between them; inside each one, the assistant just works.

  1. DefineWhat we want, and how we'll know it worked.“A contact form: name, email, message.”
  2. AnalyseHow things really are. Checked, not guessed.“The site already has a mailer.”
  3. PlanSteps in order, each one reversible.“Form, then validation, then email.”
  4. DoWork, with a dated journal of what happened.“Oct 16 — spam filter added.”
  5. CheckProve it works, for real.“Sent one. It arrived.”
  6. CloseKept forever, never deleted.“Done. Lesson: test on mobile first.”

The doorman at work

Real rules, checked before every command. Even when it's hidden inside another one, or sent over ssh.

Lose the laptop, keep the brain

Each drawer can back up to a private git repository of yours. This is what you get:

  • A new machine in minutes. augmented-brain restore brings the whole drawer back: notes, tasks, rules, your profile and its settings. Open Claude and carry on.
  • Several machines, one brain. Laptop and desktop? Each backup first fetches what the other machine did, and merges it.
  • Full history. Every backup is a git commit, with the machine and the time. See what changed, and go back to any day.
  • Your place, not ours. GitHub, GitLab or your own server: you pick the repository. augmented brain has no cloud.
  • One repository per drawer. Work can live in your company's git, and personal in yours.
  • No secrets go up. If a note holds something that looks like a password or a token, the backup stops and tells you where.
  • Nothing gets overwritten. If two machines changed the same note, it stops without touching anything and tells you how to fix it.

Set it up once

augmented-brain backup setup \ git@github.com:you/my-brain.git
augmented-brain backup

Easiest: tell Claude “set up the backup” and it creates a private repository in your GitHub. Rather somewhere else? The first command links the drawer to your repository, once. From then on the backup runs by itself every time a Claude session ends; the second saves by hand, if you like (--all for every drawer).

Start in two steps

A few minutes, on Linux, macOS or Windows, with a paid Claude account (Pro or above). Never opened a terminal? Follow getting started. What changes on each system: Installing.

  1. Install it with one command. It asks the language and offers to install what is missing: git, Claude Code and the Claude desktop appOn Linux or a Mac, in the terminal:
    curl -fsSL https://github.com/icalvete/augmented-brain/releases/latest/download/install.sh | sh
    On Windows, in PowerShell:
    irm https://github.com/icalvete/augmented-brain/releases/latest/download/install.ps1 | iex
  2. Answer Claude: the first time it asks six quick questions, and says what each one is for

It creates two spaces, work and personal, in ~/augmented-brain, and asks whether to open Claude right away. From then on, open the Claude app and click + New: without choosing a folder you are in your personal space; for work, pick ~/augmented-brain/work with Choose…. Or in a terminal: cd ~/augmented-brain/work && claude (on Windows, cd ~\augmented-brain\work; claude). If something is off, augmented-brain doctor tells you what is missing.

All the commands
augmented-brain initSets everything up: the work and personal spaces and the plugin (the installer runs it; --custom to choose yourself)
augmented-brain space addAdd another space: personal, a client…
augmented-brain doctorSay what is missing, and how to fix it
augmented-brain checkCheck this folder's notes and rebuild their index
augmented-brain backup setup <url>Back up this space to a private git repository
augmented-brain backupSave the latest changes (--all for every space)
augmented-brain restore <url>Bring a space back on a new machine
augmented-brain updateUpdate augmented brain and its Claude Code plugin (Claude tells you when there is a new version)
augmented-brain uninstallRemove the program and the plugin; your notes stay

Questions

Is it free?

augmented brain is: open source, under the MIT license, with no account and no subscription. But it works with Claude Code, which needs a paid Claude account (Pro or above).

Do my notes leave my machine?

augmented brain never sends them anywhere: they stay in files on your machine. Your assistant reads them to work, like any other file it opens, so they travel with the conversation. With a backup, they also go to a private git repository you choose.

Which assistants does it work with?

Claude Code today. The method runs as an MCP server, so any assistant that speaks MCP can use it; adapters for others will follow.

Does it work on Windows?

Yes: Windows 10 and 11, with one PowerShell command. Claude runs its commands in Git Bash, which the installer sets up, so the guard works there too. See Installing.

Can I edit the notes by hand?

Yes, they are Markdown files. Afterwards, augmented-brain check checks them and rebuilds the index.

Does the backup run by itself?

Yes. Once it is set up, it runs every time a Claude session ends, in the background. If it fails, Claude tells you at the start of the next session.

How can I support it?

Sponsor it on GitHub Sponsors. It pays for the time to answer issues and add features.

Is there paid support?

Yes, on GitHub Sponsors: the Support tier gets you an answer by email within two working days, and the Setup session is one hour on a video call to set it up with you.

What if I stop using it?

Your notes stay where they are, as plain files. There is nothing to export.
