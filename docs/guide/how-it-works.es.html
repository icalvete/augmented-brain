Cómo funciona por dentro

augmented brain es un programa pequeño y una carpeta de notas. Esta página cuenta cómo encajan las piezas. Para usarlo, no te hace falta nada de esto.

Cuatro capas

Dicho de otra forma: tus notas son un cuaderno, el programa es quien lo ordena y el plugin es la puerta. Tú solo hablas con Claude. Claude entra por la puerta y el programa escribe en el cuaderno.

Dos palabras que salen mucho:

  • Hook: un aviso que Claude Code lanza en un momento concreto. Aquí, al empezar la sesión, antes de que Claude conteste cada mensaje (para decirle qué tareas cambiaron en otra sesión), antes de cada comando y cada cambio de fichero, después de cada respuesta, cuando una conversación larga se compacta y cuando la sesión termina. En cada aviso, Claude Code arranca el programa, le pregunta y el programa termina.
  • MCP (Model Context Protocol): un estándar abierto para dar herramientas a un asistente. El programa ofrece las suyas (“abre una tarea”, “apárcala”) y Claude las usa. Al ser un estándar, otros asistentes podrán usar las mismas.

La lista de hooks está en Comandos. Las herramientas, en Herramientas MCP.

Una sesión, paso a paso

1. Abres Claude. El hook de inicio mira en qué carpeta estás y elige tu espacio. Antes de que escribas nada, le pasa a Claude tu perfil, tus reglas y la lista de tareas vivas. También le dice lo que vence pronto, si toca la revisión semanal y si una sesión anterior se cortó. Por eso Claude sabe dónde lo dejaste. Una sesión abierta para una tarea (session start) solo oye las fechas de esa tarea.

2. Dices “apárcala”. Claude usa la herramienta task_park. El programa apunta en el fichero de la tarea dónde se quedó y cuál es el siguiente paso, y rehace el índice. Abrir, retomar y cerrar funcionan igual. Mira Tareas.

3. Claude va a ejecutar un comando. El hook del guardia lo lee antes, y lo deja pasar, te pregunta o lo para. Mira El guardia.

4. Claude termina una respuesta. Si la sesión tiene una tarea abierta y en 20 minutos no se ha escrito nada en ella, un hook le recuerda a Claude que escriba en su diario, una vez. Cada sesión tiene su propia tarea, así que dos ventanas nunca reciben el aviso de la otra. En Linux y macOS, el mismo hook mira también la memoria de la ventana: si ha crecido mucho más de lo normal, Claude te lo dice, para que aparques la tarea antes de que el sistema cierre la ventana. Mira Si algo falla.

5. Cierras la sesión. El hook de cierre apunta que la sesión acabó bien. Lanza la copia de seguridad del espacio por detrás, si la has configurado. No esperas a nada. Si la red no contesta, la copia se rinde a los 3 minutos en vez de quedarse colgada. Si la copia falla, Claude te lo dice al empezar la siguiente sesión.

Si una sesión no acabó bien (se cerró la ventana a la fuerza, se apagó el ordenador), la siguiente te ofrece recuperarla. Claude lee lo que os dijisteis después de la última entrada del diario de la tarea, en el registro de la conversación que guarda Claude Code en este ordenador (lo guarda 30 días), y apunta lo que falte.

Dónde viven tus notas

Tus notas, una carpeta por espacio:

~/augmented-brain/
├── trabajo/              una carpeta de trabajo: abre Claude aquí para lo del trabajo
│   ├── notas/
│   │   ├── MEMORY.md     el índice que Claude lee al empezar (lo escribe el programa)
│   │   ├── inbox.md      apuntes rápidos, para ordenar luego
│   │   ├── areas/        lo que cuidas siempre
│   │   ├── tasks/        un fichero por tarea
│   │   ├── knowledge/    cómo funcionan las cosas y lo aprendido
│   │   ├── people/       con quién tratas
│   │   ├── rules/        reglas solo de este espacio
│   │   ├── reviews/      revisiones semanales
│   │   ├── docs/         documentos largos de una tarea; no se cargan nunca
│   │   └── archive/      lo antiguo; no se carga y no se borra
│   └── (tus proyectos)
└── personal/             lo mismo, para lo personal

Todo lo demás (la carpeta de configuración, lo que este ordenador guarda para sí, el programa) y lo que viaja en la copia está en Dónde vive cada cosa.

Lo que no hace

  • No hay servidor ni cuenta. Si Claude no está abierto, no funciona nada, salvo: - el panel, mientras lo usas; - la copia de seguridad que lanza el final de una sesión; - la sesión propia de una tarea, abierta con augmented-brain session start, hasta que se para o se cierra la tarea; - augmented-brain watch pr, que espera las comprobaciones de una pull request, tres horas como mucho; - si lo configuras, el acceso remoto, que sigue en marcha para que llegues a tus sesiones desde otro dispositivo.
  • No envía tus datos a nadie. Solo la copia de seguridad, si la configuras, habla con tu repositorio. Aparte, una vez al día, pregunta a GitHub cuál es la última versión, sin mandar nada tuyo. AB_NO_UPDATE_CHECK=1 lo apaga.
  • No toca tus ajustes de Claude Code. El plugin se pone y se quita con los comandos de Claude Code, que el instalador, update y uninstall lanzan por ti.
  • Como viene, no se queda dentro de tus espacios. Actúa en todas las sesiones de Claude Code de este ordenador. Fuera de tus espacios usa el espacio por defecto, y el guardia vigila igual. En la página Guardia del panel puedes hacer que se quede en tus espacios. Mira Fuera de todos los espacios.
  • Ojo: tu asistente lee tus notas, como cualquier fichero que abre. Viajan con tus conversaciones a su proveedor. No guardes ahí lo que no compartirías.
